# Stam Console

My personal portfolio site — single-page, no framework, built from scratch.
Boot-sequence intro, command palette (`/` to search), scroll reveals, canvas
hero background, live project video cards, and generative Web Audio sound.

Live: https://stam-console.web.app

## Stack

Plain HTML/CSS/JS, no build step. Deployed on Firebase Hosting.

## Running locally

```
firebase serve
```

or just open `index.html` directly — everything except the video/poster
assets works from the filesystem.
